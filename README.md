# عقل الحاسوب v0.1 — PC Brain v0.1

> **ما هذا؟** نسخة تدريب صغيرة من "عقل" مشروع الروبوت الزراعي.
> الحاسوب يشاهد فيديو، يكتشف الأشياء فيه (إنسان، سيارة، كلب...)،
> ويُطلق **إشارة (TRIGGER)** عند كل اكتشاف — وهذه الإشارة هي التي ستأمر
> الروبوت لاحقاً بأن يتحرك أو يفتح باباً أو يطلق إنذاراً.
>
> **لا تحتاج روبوتاً ولا إنترنت لتشغيله** (بعد التثبيت الأول).
> كل شيء يعمل محلياً على حاسوبك.

## الكلمات الصعبة — ببساطة

| الكلمة | معناها بكلمات بسيطة |
|---|---|
| **Python** | لغة البرمجة التي كتبنا بها البرنامج. |
| **YOLO11n** | نموذج ذكاء اصطناعي صغير وسريع "يرى" الأشياء في الصورة ويقول ما هي وأين هي. حرف n يعني النسخة الأصغر والأسرع. |
| **OpenCV** | مكتبة تقرأ الفيديو (من الكاميرا أو ملف أو رابط) وتعرض الصور والمربعات. |
| **WebSocket** | "خط هاتف" مفتوح دائماً بين برنامجين — هنا بين عقل الحاسوب والروبوت — يرسل الرسائل فوراً في الاتجاهين. |
| **TRIGGER (إشارة)** | سطر يطبعه البرنامج عند اكتشاف شيء، مثل: `TRIGGER: person (0.87)` — أي "رأيت إنساناً بثقة 87%". |
| **MJPEG** | فيديو مكوّن من صور JPEG متتالية — هكذا ستبث كاميرا الروبوت لاحقاً. |

## الملفات

| الملف | ما هو؟ |
|---|---|
| `brain.py` | البرنامج الرئيسي: يقرأ الفيديو، يكتشف الأشياء، ويطبع TRIGGER. |
| `config.py` | إعدادات صغيرة: مصدر الفيديو، النموذج، حساسية الكشف. عدّلها بسهولة. |
| `link.py` | خادم WebSocket ("خط الهاتف") — يبث كل TRIGGER لكل المتصلين، ويجيب على `ping` بـ `pong`. |
| `test_client.py` | اختبار صغير يثبت أن "خط الهاتف" يعمل. |
| `requirements.txt` | قائمة المكتبات اللازمة. |
| `tests/people.mp4` | فيديو اختبار (أشخاص يمشون) — لتجربة البرنامج بدون كاميرا. |

## التثبيت على Windows (خطوة بخطوة)

1. **ثبّت Python 3.11 أو أحدث** من python.org — وأثناء التثبيت ضع علامة صح على
   **"Add python.exe to PATH"** (أضف بايثون إلى PATH).
2. **افتح نافذة الأوامر (CMD)** في مجلد المشروع واكتب:
   ```
   pip install -r requirements.txt
   ```
   هذا ينزّل المكتبات (حوالي 5 دقائق أول مرة).
3. **أول تشغيل ينزّل نموذج YOLO11n** (حوالي 6 MB) — يحتاج إنترنت مرة واحدة فقط.
   بعدها يعمل البرنامج دون إنترنت.

> ملاحظة: إذا لم يكن في حاسوبك كرت شاشة قوي (GPU)، ثبّت نسخة PyTorch الخفيفة
> (CPU فقط) بهذا الأمر بدل الخطوة 2 — أصغر بكثير:
> ```
> pip install torch --index-url https://download.pytorch.org/whl/cpu
> pip install -r requirements.txt
> ```

## التشغيل

### 1) العقل وحده — بفيديو اختبار (بدون كاميرا)
```
python brain.py --source tests/people.mp4 --no-show --max-frames 300
```
**ما الذي يعني أن الأمر يعمل؟** ترى سطوراً مثل:
```
Loading model yolo11n.pt ...
Model ready. Labels it knows: 80 (person, car, dog, chair, ...).
Opening video source: 'tests/people.mp4'
TRIGGER: person (0.90) at [241, 209, 362, 430]
TRIGGER: person (0.90) at [157, 272, 313, 432]
Done. Frames read: 300, frames checked by YOLO: 59, detections: 36, triggers: 2, speed: 5.2 checked frames/second.
```
إذا رأيت سطور `TRIGGER: person ...` فالعقل يعمل — رأى إنساناً وأطلق الإشارة.

### 2) العقل مع كاميرا حاسوبك (Webcam)
```
python brain.py --source 0
```
تفتح نافذة فيها الفيديو ومربعات خضراء حول ما يكتشفه البرنامج.
للإيقاف اضغط حرف `q` في النافذة أو `Ctrl+C` في نافذة الأوامر.
(قف أمام الكاميرا وسترى `TRIGGER: person` يظهر.)

### 3) العقل مع كاميرا الروبوت (لاحقاً)
```
python brain.py --source http://192.168.1.50:81/stream
```
(غيّر العنوان إلى عنوان الروبوت الحقيقي في شبكتك.)

### 4) اختبار "خط الهاتف" (WebSocket)
افتح نافذتين (Terminal):
```
الترمينال 1:  python link.py
الترمينال 2:  python test_client.py
```
**ما الذي يعني أن الأمر يعمل؟**
```
Connected. Waiting for one trigger ...
Got trigger: {'type': 'trigger', 'label': 'person', 'confidence': 0.9, 'time': '23:41:05'}
Sending {"cmd": "ping"} ...
Got reply: {'type': 'pong'}
OK — phone line works: trigger received + ping/pong round-trip.
```

### 5) العقل + خط الهاتف معاً (الصورة الكاملة)
```
python brain.py --source tests/people.mp4 --link --no-show
```
العقل يكتشف ويبث كل TRIGGER عبر WebSocket في نفس الوقت — هكذا سيسمعه الروبوت لاحقاً.
(ملاحظة: العقل يتوقف عندما ينتهي الفيديو — شغّل `test_client.py` في الترمينال الثاني
بينما الفيديو ما زال يعمل.)

## تغيير مصدر الفيديو

- في سطر الأوامر: `--source 0` للكاميرا، `--source tests/people.mp4` لملف فيديو،
  `--source http://...` لرابط MJPEG.
- أو عدّل سطر `VIDEO_SOURCE` في ملف `config.py` مرة واحدة.

## ملاحظات مهمة

- **السرعة:** بدون كرت شاشة (GPU)، البرنامج يفحص كل إطار خامس فقط
  (`DETECT_EVERY = 5` في `config.py`) — وهذا كافٍ تماماً للتدريب.
  إذا كان حاسوبك سريعاً، جرّب `--every 2` أو `--every 1`.
- **الحساسية:** `--conf 0.5` تعني "أخبرني فقط عندما تكون متأكداً 50% أو أكثر".
  ارفعها (0.7) لإشارات أقل وأدق، أو اخفضها (0.3) لرؤية المزيد.
- **نافذة الفيديو:** على حاسوب بلا شاشة (مثل الخادم) أضف `--no-show`.
- **YOLO يعرف 80 شيئاً** (إنسان، سيارة، كلب، كرسي...) لكنه **لا يشخّص أمراض النباتات**
  — هذا دور نموذج متخصص أو السحابة في المراحل التالية.

## إذا حدث خطأ

| المشكلة | الحل |
|---|---|
| `could not open video source` مع `--source 0` | الكاميرا مستعملة من تطبيق آخر — أغلقه، أو جرّب `--source 1`. |
| `could not open video source` مع ملف | تأكد من المسار — جرّب `tests/people.mp4` من داخل مجلد المشروع. |
| `No module named 'ultralytics'` | أعد `pip install -r requirements.txt`. |
| تنزيل النموذج بطيء/يفشل | يحتاج إنترنت مرة واحدة — أعد المحاولة؛ الملف يُحفظ بجانب `brain.py`. |
| بطء شديد | زد `--every` إلى 10، أو قلل دقة الفيديو. |
